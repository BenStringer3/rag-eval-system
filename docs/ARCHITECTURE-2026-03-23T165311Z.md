## Sequence diagrams

### 1. Corpus ingestion (`RAGPipeline.ingest` / `src.rag.ingest` CLI)

```mermaid
sequenceDiagram
    actor CLI as ingest CLI
    participant Pipe as RAGPipeline
    participant Load as load_corpus
    participant Ch as RecursiveChunker
    participant VS as VectorStore
    participant Emb as Embedder
    participant API as LM Studio API
    participant DB as ChromaDB

    CLI->>Pipe: from_config(yaml)
    CLI->>Pipe: ingest(corpus_dir)
    Pipe->>Load: load_corpus(corpus_dir)
    Load-->>Pipe: list of (content, DocumentMeta)
    loop each document
        Pipe->>Ch: chunk_document(content, meta)
        Ch-->>Pipe: list Chunk
    end
    Pipe->>VS: add_chunks(all_chunks)
    loop batches
        VS->>Emb: embed_documents(texts)
        Emb->>API: POST /v1/embeddings
        API-->>Emb: vectors
        Emb-->>VS: embeddings
        VS->>DB: collection.upsert
    end
    VS-->>Pipe: done
    Pipe-->>CLI: chunk count
```

### 2. Query and answer (`RAGPipeline.query`)

```mermaid
sequenceDiagram
    actor User as Caller
    participant Pipe as RAGPipeline
    participant Ret as Retriever
    participant VS as VectorStore
    participant Emb as Embedder
    participant API as LM Studio API
    participant DB as ChromaDB
    participant Gen as Generator

    User->>Pipe: query(question)
    Pipe->>Ret: retrieve(question)
    Ret->>VS: query(question, top_k)
    VS->>Emb: embed_query(question)
    Emb->>API: POST /v1/embeddings
    API-->>Emb: query vector
    Emb-->>VS: embedding
    VS->>DB: collection.query
    DB-->>VS: ids, documents, distances
    VS-->>Ret: list RetrievedChunk
    Ret-->>Pipe: ranked chunks
    Pipe->>Gen: generate(question, retrieved)
    Gen->>API: POST /v1/chat/completions
    API-->>Gen: completion
    Gen-->>Pipe: RAGResult
    Pipe-->>User: RAGResult
```

### 3. Evaluation run (`run_evaluation`)

```mermaid
sequenceDiagram
    actor Runner as eval.runner
    participant Pipe as RAGPipeline
    participant DS as load_eval_dataset
    participant Judge as judge_model_from_config
    participant Met as get_all_metrics
    participant Map as to_deepeval_test_cases
    participant DE as DeepEval evaluate

    Runner->>DS: load_eval_dataset(path)
    DS-->>Runner: EvalDataset
    Runner->>Judge: judge_model_from_config_files(...)
    Judge-->>Runner: GPTModel (DeepEval)
    Runner->>Met: get_all_metrics(judge, thresholds...)
    Met-->>Runner: metric list
    Runner->>Map: to_deepeval_test_cases(dataset, pipeline.query_for_eval)
    loop each sample
        Map->>Pipe: query_for_eval(query)
        Pipe->>Pipe: query (retrieve + generate)
        Pipe-->>Map: answer, context strings
    end
    Map-->>Runner: test_cases
    Runner->>DE: evaluate(test_cases, metrics)
    DE-->>Runner: (side effects on metrics)
    Runner-->>Runner: build EvalReport from samples + test_cases + metrics
```
