# Architecture Snapshot · 2026-03-25T103050Z

This snapshot reflects the MLflow-native evaluation refactor. The previous DeepEval runner, report, judge, and SQLite registry layers have been removed.

## Cursor skills and commands

Agent-facing docs live under `.cursor/`. **Skills** are long-form workflows; **commands** are short prompts that point agents at the right skill and script.

```mermaid
flowchart TB
    subgraph AgentDocs[".cursor/ — agent entrypoints"]
        subgraph Skills["skills/"]
            ER["eval-registry\nMLflow UI, DB path, tags"]
            RER["run-eval-report\nrun_eval.py, wall time"]
            RR["rag-eval-runs\nmetrics, traces, triage"]
            SL["science-loop\nA/B, hypotheses, run_ab_study"]
            SA["synth-and-ingest\nsynthetic.json + ingest"]
        end
        subgraph Cmds["commands/"]
            CRun["run-eval-report.md\n→ run-eval-report skill"]
            CAn["analyze-eval-run.md\n→ rag-eval-runs skill"]
        end
    end

    CRun --> RER
    CAn --> RR
    RER --> RunEval["scripts/run_eval.py"]
    SL --> RunEval
    SL --> RunAB["scripts/run_ab_study.py"]
    ER --> RunEval
    ER --> RunAB
    ER --> MFUI["mlflow ui\nsqlite:///data/mlflow.db"]
    RR --> MFUI
    SA --> Ingest["python -m src.rag.ingest"]
```

| Path | Role |
|------|------|
| `.cursor/skills/eval-registry/SKILL.md` | Tracking URI, `run_eval` / `run_ab_study`, filtering by `study_id` and dataset tags |
| `.cursor/skills/run-eval-report/SKILL.md` | Single eval runs via `scripts/run_eval.py`, timeouts, MLflow reporting |
| `.cursor/skills/rag-eval-runs/SKILL.md` | Read runs: faithfulness, relevancy, precision, recall; trace-based debugging |
| `.cursor/skills/science-loop/SKILL.md` | Preregistered A/B workflow, `run_ab_study.py`, fixed-N pairing |
| `.cursor/skills/synth-and-ingest/SKILL.md` | Corpus → `synthetic.json` → ingest (upstream of eval) |
| `.cursor/commands/run-eval-report.md` | Command wrapper → `run-eval-report` skill |
| `.cursor/commands/analyze-eval-run.md` | Command wrapper → `rag-eval-runs` skill (MLflow, not file reports) |

## Eval sequence

```mermaid
sequenceDiagram
    actor CLI as run_eval.py
    participant DS as datasets.py
    participant SC as scorers.py
    participant MF as mlflow.genai.evaluate()
    participant Pipe as RAGPipeline
    participant Ret as Retriever
    participant Gen as Generator
    participant DB as MLflow DB

    CLI->>DS: load_mlflow_eval_data(dataset.json)
    CLI->>SC: build_scorers(configs/eval.yaml)
    CLI->>Pipe: RAGPipeline.from_config(configs/default.yaml)
    CLI->>DB: start_run(tags, params)
    CLI->>MF: evaluate(data, predict_fn, scorers)
    loop each sample
        MF->>Pipe: predict_fn(question=...)
        Pipe->>Ret: retrieve_detailed(question)
        Pipe->>Ret: trace_retrieval(question, chunks)
        Pipe->>Gen: generate(question, chunks)
        Gen-->>MF: answer
    end
    MF->>DB: log traces + scorer feedback
    CLI->>DB: log_metric(pass_rate)
```

## A/B sequence

```mermaid
sequenceDiagram
    actor CLI as run_ab_study.py
    participant CFG as ab_study_config.py
    participant MF as mlflow.genai.evaluate()
    participant DB as MLflow DB

    CLI->>CFG: write_yaml_with_overrides(control/treatment)
    loop each block
        CLI->>DB: start_run(tags: study_id, arm=a, block=n)
        CLI->>MF: evaluate(...)
        CLI->>DB: log_metric(pass_rate)

        CLI->>DB: start_run(tags: study_id, arm=b, block=n)
        CLI->>MF: evaluate(...)
        CLI->>DB: log_metric(pass_rate)
    end
```
